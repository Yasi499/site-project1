# site-project (HealthyDay)

Статичний лендінг про здоровий сніданок та збалансований режим прийому їжі протягом дня.

## Структура проєкту

- `index.html` — головна сторінка лендінгу
- `static/images/favicon.ico` — іконка вкладки браузера
- `static/lib/bootstrap-5.0.2-dist/` — стилі та скрипти Bootstrap 5.0.2
- `static/lib/jquery-4.1.0.min.js` — бібліотека jQuery 4.1.0
- `static/scripts/main.js` — власні скрипти інтерактивності
- `static/styles/reset.css` — скидання базових стилів браузера
- `static/styles/styles.css` — власні стилі оформлення сторінки
